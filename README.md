# Customer Churn Prediction Using ANN

This project is an end-to-end Customer Churn Prediction system built using Artificial Neural Networks (ANN). The model predicts whether a customer is likely to leave a company based on various customer-related features such as credit score, geography, gender, age, balance, tenure, and estimated salary.

The project includes data preprocessing, categorical feature encoding, feature scaling using StandardScaler, ANN model building with TensorFlow/Keras, model training, evaluation, and prediction. The main goal of this project is to help businesses identify customers who are at risk of churning so that they can take preventive actions to improve customer retention.

## Technologies Used
- Python
- TensorFlow / Keras
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

## Features
- Data Cleaning and Preprocessing
- One-Hot Encoding for Categorical Features
- Feature Scaling using StandardScaler
- ANN Model Training and Evaluation
- Customer Churn Prediction
- Performance Visualization

## Use Cases
- Banking Customer Retention
- Telecom Customer Analysis
- Subscription-Based Business Analytics
- Customer Behavior Prediction
